# The Gardener Was Replaced

Is a modpack about using the [Lua Programming Language](https://www.lua.org/) via [CC: Tweaked](https://tweaked.cc/) to gather flowers in their variety. This modpack is heavily inspired by [The Farmer Was Replaced](https://store.steampowered.com/app/2060160/The_Farmer_Was_Replaced/), a game with similar themes but with Python and various crops instead; if you already played this pack and liked it, go check out the game as well!

This pack includes 16 different flowers each with its own mechanic. Balance them out, create multiple scripts with crazy logic trees, complete tasks to unlock upgrades which implement further mechanics, and prove the modpack developer wrong by completing the final goal that he thought was not humanly possible!

This modpack has been made for the [Just Enough Opinions Packjam](https://discord.gg/q6awVhcPeJ), which is a competition to create the best possible pack within a ~~two~~ three-week timeframe I was really hurrying to complete this and thus did not have that much time for testing or bug hunting, so if you find anything feel free to comment!

I would also recommend joining the Discord (linked above) for the discussion of this pack, as I do not have a private server, but do/will have a thread on there where you can discuss meta-strategies with other players of this pack. Good luck and Have Fun™! ;)
